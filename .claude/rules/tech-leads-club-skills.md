# Tech Leads Club project skills

This repo has the Tech Leads Club skill pack in `.claude/skills/` (and the same files in `.cursor/skills/`).

On every task:

1. Look at `.claude/skills/*/SKILL.md`.
2. If a skill's description matches the work, read that `SKILL.md` first and follow it.
3. Load extra files it names (`references/`, `scripts/`) only when that skill says to.
4. If a skill conflicts with `CLAUDE.md` or this repo's deploy/tenant/evidence rules, those repo rules win.
